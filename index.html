How to Install

You need to own a copy of Jagged Alliance 2 (v1.0 – v1.12). JA2 Reborn does not provide any game files.

1

Create a new game directory on your device

Create a folder on your Android device where JA2 Reborn will read the game data from, e.g. /sdcard/games/jaggedalliance2.

2

Copy the game data

Copy the data folder of your Jagged Alliance 2 installation into this directory, so you end up with /sdcard/games/jaggedalliance2/data.

3

Pick the directory and choose your language

Select the game directory within the start launcher and choose the correct language of your game files.

4

Supported languages

Game files: English, German, French, Italian, Spanish, Russian, Polish, Simplified Chinese, and Dutch.

Reborn UI: English and German.

5

Unsupported add-ons and total conversions

JA2 Reborn targets the original Jagged Alliance 2 data. Unfinished Business, Wildfire, JA2 1.13, and other standalone or heavily modified JA2 data sets are not supported.

Update Changelog

JA2 Reborn 1.0.4 delivers a major touch-overlay overhaul with hand-crafted SVG icons, a dedicated Map Screen button set, a true Mouse & Keyboard mode, and dozens of widescreen and usability fixes.

Version 1.0.4 View release on GitHub

New Features

  • Completely reworked the entire icon set with mainly hand-crafted icons for every available overlay button.
  • A brand-new button set for the map screen.
  • Item stacking button for merchant and inventory panels.
  • Improved Side Step and Back Step button.
  • True Mouse & Keyboard Mode, which can be enabled in the Launcher's Expert Settings.
  • New slider in the overlay menu to adjust the click threshold between Direct Taps and Relative Mouse input.

Improvements & Fixes

  • Fixed various UI scaling issues.
  • Merchant screens and screen messages no longer switch to 4:3 mode, preventing the interface from being cropped on widescreen displays.
  • Larger Action Panel in high res mode.
Version 1.0.3 View release on GitHub

Highlights

  • New launcher resolution presets: Modern for the recommended readable UI, High Res (More Map) for more tactical map area with a smaller UI, and Retro for fixed classic 640x480 mode.
  • Expert Settings now gate manual resolution, scaling, and legacy control mode choices.
  • Menus, splash screens, videos, and map screens are presented in a centered 4:3 area so they are no longer stretched on wide displays.
  • High Res mode supports larger action panel defaults for phones.
  • Retro touch mapping was corrected for bottom-panel controls and merc portrait selection.
  • Crash reports now include crashlog-latest.txt next to the emergency savegame when possible.
